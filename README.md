# 入戏 · 酒馆风格插件集

为 [入戏 (ai-rp-chat)](https://github.com/Shawlei/ai-rp-chat) 编写的一组插件，
参考 SillyTavern 生态里最受欢迎的两类扩展重新实现（未复制其源码）。

## 插件

### 消息摘要 `summarize/`
逐条摘要聊天消息，把长对话压缩成可注入的上下文。参考 MessageSummarize 的思路，
但改用宿主的 `registerContextInjection` 做静默注入，不需要额外的"摘要提示词"手工粘贴。

- 自动摘要：生成结束后按阈值触发，摘要只对**已确认的结果**（整轮完成）生效
- 手动摘要：可指定任意条消息单独总结
- 上下文注入：把最近 N 条摘要拼接后注入提示词，避免长对话撞上下文上限
- 摘要与消息内容做指纹绑定，消息被编辑后自动标记失效

### 世界书诊断器 `deeplore/`
逐条回答「这个世界书条目为什么没生效」。

宿主的全世界书面板已经能告诉你**命中了什么**，但不会告诉你**为什么没命中**。
条目不生效时用户只能猜：关键词写错了？被次要关键词的 NOT 规则排除了？
被扫描深度挡在窗口外？

本插件在本地复算宿主的匹配规则，逐条给出结论：关键词没命中 / 被规则挡下 /
没设关键词 / 已停用 / 生效。**匹配逻辑与宿主逐例一致**（含 384 组对照测试）。

诊断只是旁路分析，不会改动世界书，也不影响实际生成。

## 安装

在入戏的「插件商店 → 本店插件」里安装，或手动添加本仓库对应子目录的地址。

## 开发

每个插件是一个含 `manifest.json` + `index.js` 的目录，符合入戏的插件契约：

```json
{ "name": "...", "version": "1.0.0", "js": "index.js", "css": ["style.css"] }
```

入口内通过 `window.__ruxiRequire('script.js')` 拿到宿主 API。
